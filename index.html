Low-Acid Food Helper

Quick LPR-friendly food ideas for lunch, snacks, and grocery-store moments.

Heads up: This is practical food guidance, not medical advice. LPR triggers vary by person. Use your clinician’s plan if it differs.
Preferences

Try asking:

  • “I’m at Publix. What can I buy?”
  • “What about nuts?”
  • “Give me a boring but safe lunch.”
  • “Is yogurt okay for LPR?”

Need a follow-up note?

This applet can prepare a clean prompt and copy it to the clipboard. The app itself stays local and never sends it anywhere.

Mini trigger log

Save quick notes locally on this phone. Nothing is uploaded.

iPhone setup

  1. Host this folder as a static website, for example GitHub Pages, Netlify, Cloudflare Pages, or any HTTPS host.
  2. Open the link in Safari on your mom’s iPhone.
  3. Tap Share → Add to Home Screen.
  4. Name it Low Acid.

For a no-hosting test, open index.html from Files, but Home Screen install works best from an HTTPS website.
